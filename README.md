# حاسبة تمويل السيارات

هذا المستودع يحتوي ملفات الواجهة المبنية فقط (`site/`) التي ينشرها GitHub Pages كما هي، دون بناء ودون أسرار.

- الكود المصدري محفوظ بشكل خاص خارج هذا المستودع.
- لا يحتوي هذا المستودع أي قوائم أسعار أو كتالوج أو دليل بنوك أو بيانات عملاء أو مفاتيح سرية.
- البيانات تُقرأ بعد تسجيل الدخول فقط، ومحمية بـ Supabase Auth وسياسات RLS.
