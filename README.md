# حاسبة تمويل السيارات

أداة داخلية عربية لحساب عروض تمويل السيارات بالفائدة/الربح السنوي الثابت على أصل مبلغ التمويل، مع حفظ العروض والعملاء خلف تسجيل دخول.

- الواجهة: React وTypeScript وVite، منشورة كملفات ثابتة على GitHub Pages.
- البيانات والدخول: Supabase (الخطة المجانية)، مع RLS على كل جدول وحساب واحد مصرّح.
- قوائم الأسعار الفعلية **ليست** في هذا المستودع؛ تُحفظ في قاعدة البيانات خلف الصلاحيات.

## طريقة الحساب

```
P = سعر السيارة، D = المقدم، L = P − D، r = النسبة السنوية ÷ 100، n = عدد الأشهر
الفوائد/الربح = L × r × (n ÷ 12)
إجمالي الأقساط = L + الفوائد
القسط الشهري = إجمالي الأقساط ÷ n
الكاش عند الاستلام = D + المصاريف المعروفة + التأمين المعروف + الرسوم − كاش باك مؤكد الخصم عند الاستلام
```

البند غير المحدد لا يُحسب صفراً: يظهر «الكاش المعروف حتى الآن» مع قائمة النواقص.

## بنية المشروع

| المسار | المحتوى |
| --- | --- |
| `src/engine/` | محرك الحساب واختيار النسبة من القوائم ونص المشاركة، مستقل عن الواجهة |
| `src/state/` | حالة المسودة، تقييمها، ولقطات العروض المحفوظة |
| `src/data/` | طبقة Supabase، والنسخ الاحتياطي (وواجهة اختبار محلية لا تدخل في بناء الإنتاج) |
| `src/ui/` | الشاشات والمكونات |
| `supabase/migrations/` | الجداول والصلاحيات وسياسات RLS |
| `supabase/tests/` | اختبار RLS على PostgreSQL محلي |
| `scripts/` | تحويل ملف الأسعار الخاص، وأداة إعداد Supabase والتحقق الأمني |
| `tests/` | اختبارات المحرك بأرقام اصطناعية |

## دليل الصيانة المختصر

### تشغيل الاختبارات والبناء

```bash
npm ci
```

```bash
npm test
```

```bash
npm run build
```

النشر تلقائي: أي دفع إلى الفرع `main` يشغّل GitHub Actions فيختبر ويبني وينشر على GitHub Pages.

### إعدادات البناء العامة

الملف `.env.production` يحتوي فقط على رابط مشروع Supabase والمفتاح المنشور (publishable) واسم المستخدم ونطاق المعرّف الداخلي. هذه قيم عامة بطبيعتها؛ الحماية الفعلية في Supabase (المصادقة وRLS). لا تضع في المستودع أبداً مفتاح `service_role` أو `secret` أو كلمة مرور أو ملف الأسعار الخاص.

### تحديث الأسعار

من داخل التطبيق: الإعدادات ← عرض وتعديل القوائم ← عدّل الخانات ← «حفظ كإصدار جديد». الأصل يبقى محفوظاً، و«استعادة القيم الأصلية» تعيد تفعيله. العروض المحفوظة لا تتغير.

### كلمة المرور

تُغيَّر من داخل التطبيق فقط (الإعدادات ← تغيير كلمة المرور). لا توجد استعادة بالبريد. إذا فُقدت كلمة المرور، يعيد المسؤول تعيينها من لوحة Supabase: Authentication ← Users ← المستخدم ← Reset/Update password.

### الخروج بعد الخمول وحدود الجلسات

- الخروج التلقائي يُطبَّق من التطبيق (افتراضياً 30 دقيقة، قابل للتعديل من الإعدادات) ويُلغي جلسة التحديث على الخادم.
- عمر رمز الدخول (JWT) مضبوط على مدة قصيرة؛ الرمز الصادر قبل الخروج يبقى صالحاً تقنياً حتى انتهاء عمره.
- إنهاء الجلسات بالخمول أو تحديد عمرها من جهة الخادم ميزات مدفوعة في Supabase، ولم تُفعَّل.

### إذا أوقف Supabase المشروع المجاني بسبب الخمول

المشاريع المجانية تتوقف مؤقتاً بعد فترة بلا نشاط، فتظهر في التطبيق رسالة تعذّر الاتصال.

1. ادخل إلى لوحة Supabase بحساب المالك.
2. افتح المشروع واضغط **Restore project** (استئناف المشروع)، وانتظر حتى يعود للعمل (عادة دقائق).
3. أعد فتح التطبيق وسجّل الدخول. البيانات تبقى كما هي.

وفق صفحتي Supabase الرسميتين (الأسعار، ودليل إيقاف المشاريع المحدّث في 22 سبتمبر 2026، وتمت مراجعتهما في 24 نوفمبر 2026):
- يتوقف المشروع المجاني بعد أسبوع من قلة النشاط، ويمكن استئنافه من اللوحة.
- حدود الخطة المجانية: مشروعان نشطان، وقاعدة بيانات 500 ميجابايت، و50,000 مستخدم نشط شهرياً، و5 جيجابايت نقل بيانات.
- **النسخ الاحتياطي التلقائي غير مشمول في الخطة المجانية.** صدّر نسخة احتياطية من الإعدادات بانتظام (أسبوعياً مثلاً) واحفظها في مكان خاص.

الاستخدام المنتظم للأداة يمنع التوقف عادة. راجع الصفحتين عند الحاجة لأن الحدود قد تتغير.

### النسخ الاحتياطي

الإعدادات ← تصدير نسخة احتياطية. الملف خاص ويحتوي العملاء والعروض وإصدارات القوائم دون كلمات مرور. الاستيراد يعرض معاينة (جديد/مكرر) قبل الدمج أو الاستبدال.

### إعادة الإعداد من الصفر (للمسؤول)

```bash
PROJECT_REF=<ref> OUT_DIR=<مجلد خاص خارج المستودع> RATEBOOK=<ratebook.json خاص> SITE_URL=<رابط الموقع> node scripts/setup-supabase.mjs
```

الأداة تطبّق الجداول والسياسات، وتقفل التسجيل العام والدخول المجهول، وتنشئ الحساب الواحد بكلمة مرور قوية تُكتب في الملف الخاص فقط، وتستورد الأسعار، ثم تختبر الوصول بلا جلسة وبمستخدم آخر.
